## Описание:
REST API бэкенд системы бронирования и создания гостиничных номеров.

## Быстрый старт:
### Сначала поднимаем и собираем образ с проектом с помощью следующих команд:
**Сборка образа**
```bash
docker build -t django-hotel-api:latest .
```
**Запуск docker-compose который поднимает контейнер с постгрес и затем контейнер с проектом**
```bash
docker compose up
```
### Запускаем миграцию моделей в БД
**Подключение к контейнеру и запуск миграции**
```bash
docker compose exec api python manage.py migrate
```

## Переменные окружения
В проекте есть .env-example, в нем указаны все переменные, которые должны быть заполнены перед запуском docker-compose
В частности это следующие переменные:
```text
#Настройки для самого приложения
DEBUG=False
SECRET_KEY=dummy-key-for-ci
ALLOWED_HOSTS=127.0.0.1,localhost

#Данные для подключения к БД
DB_NAME=dummy_db
DB_USER=dummy_user
DB_PASSWORD=dummy_pass
DB_HOST=127.0.0.1
DB_PORT=5432
```

## Установка
Для запуска проекта на локалке необходимо запустить контейнер с postgres:18 и установить зависимости с помощью команды
```bash
uv sync --frozen
```

## Тесты
Для запуска тестов, необходимо запустить pytest, желательно с флагом -v, чтобы видеть результаты всех тестов
```bash
uv run pytest -v
```
